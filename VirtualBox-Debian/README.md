# VirtualBox ile Debian 13 Kurulumu

## Proje Hakkında

Oracle VirtualBox kullanılarak Debian 13 işletim sistemi için
sanal makine oluşturulmuş ve işletim sistemi kurulumu gerçekleştirilmiştir.

## Yapılan Çalışmalar

- VirtualBox üzerinde sanal makine oluşturuldu.
- Debian 13 kurulumu gerçekleştirildi.
- Sanal makine kaynakları yapılandırıldı.
- Debian masaüstü ortamı çalıştırıldı.
- Firefox tarayıcısı açılarak test edildi.

## Kullanılan Teknolojiler

- Oracle VirtualBox
- Debian 13
- Firefox
